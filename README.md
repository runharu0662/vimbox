# Vimbox

Neovimで使う、思いつきを蓄えて順番に処理するFIFO inboxです。
Neovim 0.10以降が必要です。

## インストール

lazy.nvimの場合:

```lua
{ dir = "~/projects/vimbox", cmd = "VimboxOpen" }
```

GitHubからインストールする場合:

```lua
{ "runharu0662/vimbox", cmd = "VimboxOpen" }
```

設定を変更せず、ローカルのコードを試す場合:

```sh
nvim -c 'set runtimepath^=/Users/runharu/projects/vimbox' \
  -c 'runtime plugin/vimbox.lua' -c 'VimboxOpen'
```

`:VimboxOpen` で開きます。入力欄にフォーカスした状態で起動します。

| 場所 | キー | 操作 |
| --- | --- | --- |
| 入力欄 | Enter | 入力を末尾に追加 |
| 入力欄 | Tab | 一覧へ移動 |
| 一覧（ノーマルモード） | i | 入力欄へ移動 |
| 一覧（ノーマルモード） | d | 最も古い項目を処理済みにする |
| 一覧（ノーマルモード） | r / e | カーソル位置の項目を訂正 |
| 訂正中の入力欄 | Enter | 順番を変えずに保存 |
| 訂正中の入力欄 | Esc | 変更をキャンセルして一覧へ戻る |
| 共通（ノーマルモード） | q | 閉じる |
| 共通 | Ctrl-c | 閉じる |

一覧は古い順に並び、先頭の ▶ が次に処理する項目です。
カーソルの位置によらず、`d` は常に先頭を取り出します。
空白だけの入力は追加されません。
訂正も空白だけでは保存できません。訂正前の追加入力の下書きは保存・キャンセル後に復元されます。
訂正中は先頭項目の処理を停止します。Enterで保存するかEscでキャンセルしてから処理してください。

データは `stdpath("data")/vimbox_queue.json` に自動保存されます。
複数のNeovimからの同時編集には対応していません。

## 選択と保存

開いた直後は入力欄にフォーカスします。一覧の初期選択は先頭で、選択行は背景色で強調します。
`j` / `k` は項目単位で移動し、先頭・末尾では止まります。折り返した文章も1項目です。
追加後は入力欄に留まり、訂正の保存・キャンセル後は一覧に戻ります。
`d` は確認なしで先頭を処理し、結果を通知します。空のキューでは変更しません。
一覧の移動や開閉では保存データを変更しません。

保存は一時ファイルへの書き込み後に置き換えます。保存失敗時はエラーを通知し、メモリ上のキューを変更しません。
読み込みに失敗した場合はエラーで停止し、元のファイルを保持します。
期限、タグ、処理済み履歴、選択項目の削除は対応範囲に含みません。

## Lua API

- `require("vimbox").open()`: UIを開く。
- `require("vimbox.queue").list()`: キューのコピーを返す。
- `queue.push(text)` / `queue.rename(index, text)`: 成功時にtrue、入力不正または保存失敗時にfalseを返す。indexは1から始まる。
- `queue.pop()`: 先頭の文字列を返す。空または保存失敗時はnilを返す。
- `vimbox.storage`: JSONの読み込み・保存を担当する内部モジュール。

## 検証

Neovimだけで実行できます。テストは一時ディレクトリを使い、通常のキューを変更しません。

```sh
nvim --headless -u NONE -i NONE -l tests/run.lua
nvim --headless -u NONE -i NONE -l tests/input.lua
```
